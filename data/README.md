# Dataset

**Real dataset:** Sakar, C. & Kastro, Y. (2018), *Online Shoppers Purchasing Intention Dataset*, UCI Machine Learning Repository. DOI: https://doi.org/10.24432/C5F88Q. Licensed CC BY 4.0.

- Original URL: https://archive.ics.uci.edu/dataset/468/online+shoppers+purchasing+intention+dataset
- Original filename: `online_shoppers_intention.csv`
- 12,330 rows; 18 original columns. Rows represent sessions.
- The CLI attempts to download it automatically. If offline, download manually and place the CSV here.
- The original UCI dataset is **not included** inside this ZIP.

**Note:** `--demo` builds its own synthetic sessions exclusively for offline testing. Demo reports are clearly marked synthetic and must never be presented as analysis of real users.
